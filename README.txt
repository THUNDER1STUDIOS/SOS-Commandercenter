SOS COMMANDER CENTER
Thunder Studios · Windows-PC · Offline-Simulation

START / START
Double-click SOS Commander Center.exe. Keep the _internal folder next to
the EXE. Python, Qt and the other runtime libraries are bundled. The game
does not download or install dependencies when it starts.

Beim ersten Start erscheint die Sprachauswahl vor dem Intro. Wähle English
oder Deutsch. Die Auswahl wird lokal gespeichert. Anschließend kannst du
eine Karriere mit Feuerwehr, Rettungsdienst und/oder Polizei beginnen.

NOTRUFE / CALLS
Ruhig: ein neuer Anruf alle 5 echten Spielminuten.
Normal: alle 3 Minuten. Häufig: alle 2 Minuten.
Sehr häufig: jede Minute. Pause und Hauptmenü stoppen den Anruftimer.
Die Häufigkeit kann auch während einer Karriere in den Einstellungen geändert
werden. Der Countdown steht unter der Notrufannahme.

BEDIENUNG / CONTROLS
Leertaste: pausieren · F1: Tutorial · Strg+S: speichern · Strg+Z: rückgängig.
Spielstand und Einstellungen: %LOCALAPPDATA%\ThunderstromLeitstelle

WICHTIG / IMPORTANT
Alle Einsätze sind erfunden. Die Simulation ist nicht mit echten Leitstellen,
Behörden, Telefon- oder Notrufnetzen verbunden. Für echte Notfälle bitte die
geltenden offiziellen Notrufwege nutzen.

This is a fictional simulator and does not connect to real emergency services.
The English edition includes an offline text catalog for menus, calls, radio
messages, reports, and synthesized speech. Windows needs a local English
voice installed for English speech; otherwise all information stays visible
as text. The choice of voice affects how natural it sounds.

RELEASE NOTES
Keep the complete folder together. THIRD_PARTY_NOTICES.txt and Licenses
must accompany the EXE. RIGHTS_NOTICE.txt explains the game's proprietary
terms. The game's own source is not distributed, but Python
bytecode inside an EXE is not a strong copy-protection measure. Before a
commercial release, arrange a native-speaker review of English wording and a
legal review of the bundled libraries, trademarks, and store requirements.
